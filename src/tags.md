# Browse by tag

Every public post carries one *type* tag plus a few *topic* tags, so you can
jump straight to the kind of content you want:

- **Thoughts & philosophy** — [`thoughts`](#tag:thoughts), [`philosophy`](#tag:philosophy)
- **Portfolio / projects** — [`portfolio`](#tag:portfolio), [`project-write-up`](#tag:project-write-up)
- **Technical knowledge** — [`snippet`](#tag:snippet), [`til`](#tag:til), [`learning-notes`](#tag:learning-notes), [`paper-notes`](#tag:paper-notes)
- **Problem solving** — [`problem-solving`](#tag:problem-solving), [`leetcode`](#tag:leetcode), [`advent-of-code`](#tag:advent-of-code)

Topic tags (`nlp`, `llm`, `pytorch`, `low-level`, `agentic-ai`, …) cut across
the types.
